## Fit, then fill

Fit a model to training spectra, then predict the masked pixels of other spectra.

```python
import gspice

model, clipped = gspice.fit(train.flux, train.ivar)
result = gspice.infill(model, flux, ivar, mask=mask)
result.flux  # the input, with the masked pixels replaced
result.var  # the variance of each pixel
```

Each array has the shape (number of spectra, number of pixels). The
[Quickstart](/GSPICE/start/quickstart/) runs this code on simulated spectra.
